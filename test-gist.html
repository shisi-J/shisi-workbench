☁️ Gist 备份测试工具

列出当前 GitHub Token 下的所有 Gist，查看诗思工作台的云端备份情况

🔑 填写 GitHub Token
💡 Token 从哪里来？打开诗思工作台设置页可以看到已配置的 Token。由于 Token 存储在浏览器的 IndexedDB / localStorage 中，服务器端无法直接读取，所以需要在这里手动粘贴一次。
本工具调用的是 GitHub 官方接口 GET https://api.github.com/gists?per_page=100，请求仅发送到 GitHub，不经过任何第三方服务器。
请在上方填写 Token 后点击「查询所有 Gist」
