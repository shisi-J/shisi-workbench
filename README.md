# 诗思 · 个人工作台

管理工作·学习·生活的个人移动 PWA 工作台。

## 功能模块

- **首页** - 天气问候、今日待办、工作台快捷入口、生活日志、学习成长
- **日程待办** - 日历视图/看板视图/列表视图，多级子任务，重复模板
- **学习成长** - 学习表达/英语/新媒体/理财，视频链接收藏与打卡
- **灵感库** - 全网链接收藏，分享口令自动解析，AI标签
- **播客** - 小宇宙/B站/抖音播客收藏与收听打卡
- **工作模块** - 项目/采购/财务台账管理
- **生活模块** - 美食探店/美妆穿搭/旅游游记/安家置业/个人财务/社交
- **感悟输出** - 学习笔记/实践作品/总结复盘，关联来源
- **能量工作台** - 体重管理为核心
- **AI 对话** - 集成 OpenAI 兼容 API

## 技术架构

- 纯前端，无后端依赖
- IndexedDB + AES 加密本地存储
- PWA 离线可用，支持 iPhone 添加到主屏幕
- Service Worker network-first 缓存策略

## 数据备份

1. 进入「设置」→「数据管理」
2. 点击「导出」生成 AES 加密的 JSON 备份文件
3. 更换设备时点击「导入」从备份文件恢复

## 本地开发

```bash
# 使用任意静态服务器
npx serve .
# 或
python -m http.server 8080
```
